Install OfficerLab as an app

Windows PC (Chrome / Edge): Click Install OfficerLab, or use the browser menu → Install OfficerLab / Apps → Install this site as an app.

Android (Chrome): Tap Install OfficerLab, or ⋮ → Install app / Add to Home screen.

iPhone / iPad (Safari): Share → Add to Home Screen.

Open OfficerLab online once before using it offline. The app shell and built JS/CSS are cached; AI, cloud rendering, PPT conversion and external PDF services still need internet.
