# Vercel deployment checklist

- [ ] Upload this folder to a GitHub repository.
- [ ] Import repository into Vercel.
- [ ] Set framework preset to Vite.
- [ ] Build command: `npm run build`
- [ ] Output directory: `dist`
- [ ] Deploy and test on HTTPS.
- [ ] Test camera/microphone permissions on desktop and Android.
- [ ] Configure a separate Python/FFmpeg rendering worker before advertising full MP4 export.
- [ ] Add authentication, persistent storage and secure API proxy before multi-user release.
